# 羽球戰術模組查證底稿

查詢日期：2026-09-07。本版先把戰術轉為「可被教練選取的訓練模組」，不宣稱是唯一或完整的羽球戰術分類。

## 系統中的 A–D 戰術

| ID | 模組 | 訓練意圖 | 來源對應 |
| --- | --- | --- | --- |
| TAC-A | 拉吊突擊 | 以高遠與吊球調動對手，製造失位後進攻 | 空間創造、出球選擇與後場進攻 |
| TAC-B | 攻守轉換 | 防守時以擋網、平抽轉攻；球路上挑時轉側並防守 | BWF Level 1 所述前後進攻、左右防守與轉換 |
| TAC-C | 雙打輪轉 | 球員依出球與壓力狀態，在前後與左右陣形間轉換 | BWF Level 1 雙打站位與 channel attack |
| TAC-D | 發接發前三拍 | 用限制情境訓練發球、接發與第三拍主動權 | 戰術問題解決與開球套路 |
